# Phase 2 风险表

| 风险 | 控制措施 | 当前状态 |
| --- | --- | --- |
| Sidecar 绑定到外网地址 | 只接受 `127.0.0.1`，随机端口；协议测试拒绝其他 host | 已关闭 |
| 本机其他进程调用引擎 | 每次进程启动生成 256 位 Bearer Token；日志不记录 Token | 已关闭 |
| 用户需要自行安装 Java | 安装包携带锁定 Temurin 21 jlink Runtime | 自动验证通过，待干净机确认 |
| 引擎或 JRE 被替换 | JDK、Fat JAR、Release ZIP 均锁定 SHA-256 | 已关闭 |
| 长任务无法取消 | DELETE 协作取消后终止进程树；下次操作重启 | 自动验证通过，待人工复核 |
| 应用退出后遗留 Java | `/shutdown`、3 秒宽限、Windows 进程树强制清理 | 自动验证通过，待人工复核 |
| 迁移破坏 v1 项目 | 仅迁移活动副本，首次保存前备份，事务回滚测试 | 已关闭 |
| 预览误写回正式数据 | 结果只保存在 React 内存；Service 无提交结果接口 | 已关闭 |
| 原型页面误启动引擎 | `live` 边界和 Cypress 原型隔离测试 | 已关闭 |
| 真实空项目误回退到原型数据 | 真实项目快照优先；零语言保持空列表；Cypress 覆盖创建第一门语言 | 修复完成，待外部复验 |
| Tauri verbatim 资源路径导致 Java 无法加载 JAR 主类 | 文件校验后移除 `\\?\`/`\\?\UNC\` 前缀；覆盖中文和空格路径测试 | 修复完成，待外部复验 |
| Sidecar 成功响应省略空字段导致界面白屏 | Rust IPC 与前端 Adapter 双层规范化返回值；使用真实最小响应做回归测试 | 本机安装版回归通过，待外部复验 |
| Evolution 可读取真实词典但桌面词典无写入入口 | 新桌面词典经 Application Port 读取和保存 Lexeme/Sense；Cypress 覆盖空词典创建 | 修复完成，待外部复验 |
| 正常关窗跳过项目关闭而误报异常退出 | 统一拦截标题栏、菜单和系统关闭请求；先关闭项目并清理工作区，再允许窗口关闭 | 修复完成，待外部复验 |
| 关闭监听默认调用未授权的 `destroy` 导致所有窗口无法关闭 | 最终关窗前解除监听，再调用已授权的 `close`；不扩大 capability | 本机原生进程验证通过，待外部复验 |
| 安装路径含中文或空格 | 参数不经 Shell 拼接，路径使用 `PathBuf` | 自动验证通过，待外部路径复核 |
| GPL/JRE 法律文件遗漏 | 安装资源包含 GPL、Runtime `legal/`、第三方声明与 SBOM | 自动验证通过 |
| 引擎升级改变规则语义 | 固定上游提交；完整运行 Lexurgy 上游测试 | 已关闭 |
