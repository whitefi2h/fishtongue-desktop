# Phase 2 干净 Windows 人工验收指南

适用电脑：Windows x64，未安装 Java、Node.js、Docker；建议先断网。全程只需安装
和点击 FishTongue，不需要运行代码。

## 验收前

1. 下载本次 NSIS 安装包。
2. 右键安装包，选择“属性”；记录文件大小。
3. 用系统 PowerShell 执行以下命令，把路径替换为安装包实际位置：

   ```powershell
   Get-FileHash "C:\你的下载目录\FishTongue_0.2.0-phase.2_x64-setup.exe" -Algorithm SHA256
   ```

4. 确认结果与验收报告中的 SHA-256 完全一致。

## 操作步骤

1. 安装并启动 FishTongue。打开任务管理器，确认尚无 `java.exe` 或 `javaw.exe`。
2. 新建一个项目，添加一门语言；也可打开 Phase 1 的 `.fishtongue` 项目。
3. 保存后关闭并重开项目，确认项目仍可用。这会验证 v1 数据安全升级到 Schema v2。
4. 进入该语言的“演化”。此时任务管理器应出现由 FishTongue 管理的 `javaw.exe`。
5. 输入以下规则并点击“验证”：

   ```text
   raising:
     a => e
   ```

   应显示验证通过和规则数量。
6. 故意删除规则名后的冒号，再次验证。界面应显示错误行列，编辑器光标自动定位。
7. 恢复合法规则，在测试词中输入 `ama`，点击“运行预览”。结果应为 `eme`。
8. 切换到“当前词典”输入源运行一次；结果只显示为预览，原词条不能改变。
9. 检查中间阶段/追踪信息；若部分词失败，界面不能显示“全部成功”。
10. 发起较长任务并点击“取消”。界面应恢复可操作；再次运行时引擎可重新启动。
11. 运行任务时在任务管理器结束 `javaw.exe`。项目应保持可用，再次验证可重启引擎。
12. 进入“形态学 → 屈折系统”，创建后缀或固定词形规则，添加测试词干并运行。
13. 关闭项目后重新打开。屈折规则和测试输入应保留，之前的生成结果不应保留。
14. 确认音变/屈折结果没有修改词典，也没有创建语言阶段。
15. 退出 FishTongue。等待 5 秒，任务管理器中不应残留 FishTongue 启动的 Java 进程。
16. 断网重新启动并重复一次验证与屈折运行。
17. 卸载、重装，再打开原项目；数据应保持正常。

