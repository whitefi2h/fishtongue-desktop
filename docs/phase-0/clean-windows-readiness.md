# Phase 0 干净 Windows 环境检查

> 检查日期：2026-07-23
> 结论：当前电脑不能提供合格的干净 Windows；需要外部测试机或 Windows 虚拟机

## 当前电脑为什么不合格

当前电脑是 Windows 家庭中文版，并已安装 Node.js、Rust、Git、C++ Build Tools
和其他开发工具。即使安装程序在本机运行成功，也不能证明普通用户不需要这些工具。

本机隔离能力检查结果：

| 隔离方式        | 结果                                               |
| --------------- | -------------------------------------------------- |
| Windows Sandbox | 不可用；系统中没有 `WindowsSandbox.exe`            |
| Hyper-V         | 不可用；没有 Hyper-V 计算服务或管理程序            |
| VirtualBox      | 未安装                                             |
| VMware          | 未安装                                             |
| WSL             | 可用，但它是 Linux 环境，不能验收 Windows 安装程序 |

不卸载当前开发工具，也不临时安装虚拟化软件来伪造干净环境。前者可能破坏开发环境，
后者会增加系统驱动、虚拟化和重启风险，均超出 Phase 0 本次检查范围。

## 已经完成的替代证据

当前开发机已经通过两次 NSIS 安装、应用启动、编辑、完整卸载、重装、开始菜单启动
和进程清理。这证明安装流程本身可重复，但不能替代独立环境验收。

## 完成 P0-09 所需环境

准备一台 Windows 10/11 x64 测试机或全新 Windows 虚拟机，并确认未安装：

- Node.js；
- Rust；
- Git 和 C++ Build Tools；
- Docker、Neo4j、Java。

在该环境按顺序执行：

1. 核对安装包 SHA-256；
2. 安装 FishTongue；
3. 从开始菜单启动并完成编辑器验收；
4. 断网后重新启动并编辑；
5. 关闭应用并确认没有残留进程；
6. 卸载，确认安装目录和快捷方式已清除；
7. 再次安装和启动。

完成后把结果写回 `acceptance-report.md`，P0-09 才能改为通过。
