# FishTongue Phase 3 外部人工验收

使用没有安装系统 Java 的 Windows x64 电脑。建议复制一份 Phase 2 项目作为测试文件。

安装包：`FishTongue_0.3.0-phase.3_x64-setup.exe`

SHA-256：
`C32A43CFF0856779F92B48463DACB237FEA3275781568CFAE3158419FD37826E`

逐项验收：

1. 校验安装包 SHA-256，安装 FishTongue，并确认电脑没有预装 Java。
2. 打开 Phase 2 项目，正常保存后重新打开，确认 Schema v3 迁移没有丢失旧数据。
3. 新建词条，填写词形、IPA、词性、状态、来源和备注，并添加至少两个独立词义。
4. 关闭项目并重新打开，确认词条及多个词义全部保留。
5. 创建至少三种不同类型的语素，把它们关联到词条并调整顺序。
6. 建立包含多字符音位的造词配置，保存后重新打开确认配置仍在。
7. 选择 Swadesh 100，使用固定种子生成候选，并记录前十项结果。
8. 使用相同配置、种子和概念顺序再次生成，确认结果逐项相同。
9. 只修改种子再次生成，确认结果发生变化且旧审核批次没有被覆盖。
10. 分别测试重复、禁配和无解配置，确认显示错误且词典没有新增词条。
11. 在同一批次中接受、拒绝并手工修改不同候选。
12. 关闭项目并重新打开，确认审核进度和修改后的候选保留。
13. 提交接受候选，确认只有接受项进入词典，拒绝和待审核项没有进入。
14. 选择源词和语素进行批量派生，处理重复或非法形式后提交。
15. 撤销最近一次 Phase 3 批量提交，确认相关词条被移除、候选回到待审核。
16. 再次提交后手工修改其中一个词条，然后尝试撤销，确认整批撤销被安全阻止。
17. 启动较长生成任务并取消；再手动结束 Lexurgy 进程，确认项目数据不受损且引擎可重新启动。
18. 分别运行一次真实音变验证/预览和屈折预览，确认 Phase 2 能力正常。
19. 退出 FishTongue，在任务管理器确认没有 FishTongue 所属的 Java/Lexurgy 进程残留。
20. 保持断网，卸载并重装应用，再次打开原项目，确认词典、语素、配置和审核批次仍在。

任何一步出现数据丢失、半批词条、无法退出或残留进程，都应停止验收并记录为严重问题。
