# FishTongue Phase 3 外部人工验收

使用没有安装系统 Java 的 Windows x64 电脑。

1. 安装并断网启动 FishTongue。
2. 打开 Phase 2 项目，确认项目可正常迁移并保存。
3. 新建带 IPA、状态、来源、备注和多个词义的词条，重启后核对。
4. 创建多个类型的语素并关联词条。
5. 建立含多字符音位的造词配置。
6. 使用固定种子和 Swadesh 100 生成两次，逐项比较结果。
7. 修改种子，确认结果变化。
8. 接受、拒绝和编辑候选，重启后继续审核。
9. 批量提交接受候选，确认拒绝候选未写入。
10. 批量派生并解决重复或非法形式。
11. 撤销提交并核对词典与候选状态。
12. 修改已提交词条后再次撤销，确认操作被安全阻止。
13. 取消长任务并手动结束 Sidecar，确认项目不受损。
14. 回归音变与屈折。
15. 退出后确认没有 FishTongue 的 Java/Lexurgy 进程。
16. 卸载、重装并重新打开原项目。
