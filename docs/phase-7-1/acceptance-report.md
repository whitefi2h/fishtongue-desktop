## 自动验收记录

### 2026-08-14 首轮人工验收问题修复

- 全局撤销或重做成功后，当前工作区会立即重新读取项目数据；不再需要离开历史事件、阶段等页面再返回。
- 从外部入口进入有历史阶段的语言时，阶段读取会过滤内部默认状态与方言，并防止上一次异步请求覆盖当前语言；读取完成前显示“正在读取阶段”，不再误显默认阶段。
- 有数据的历史阶段词典恢复编辑、保存和删除；只有 `no_data` 无记录阶段保持只读。
- 新增组件回归测试，分别覆盖历史事件原地刷新、外部进入后选择首个历史阶段，以及历史阶段词典底部保存/删除按钮可用。

### 2026-08-14 第二轮人工验收问题修复

- 实际验收数据库的阶段查询耗时约 `0.15 ms`，确认问题不在 SQL 数据量，而在前端加载状态只有成功分支能够结束。
- 新建语言可确定尚无历史阶段，现在立即显示“默认状态”，阶段查询在后台完成，不再阻塞路径栏。
- 阶段查询异常会立即结束加载并显示具体原因；超过 3 秒仍未返回则判定超时，不再无限显示“正在读取阶段…”。
- 失败或超时后，阶段菜单提供“重新读取阶段”操作。
- 新增成功、失败重试和超时三条组件回归路径；其余两项首轮问题保持通过状态。
