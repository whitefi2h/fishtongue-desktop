# Phase 7.1 Windows 人工验收指南

> 验收结果：维护者于 2026-08-14 完成最终复验并确认通过，Phase 7.1 已正式结项。

> 目标：确认真实桌面安装包中的撤销/重做、阶段词典和导航符合预期。请使用测试项目，不要直接使用唯一的正式项目副本。

## A. 安装与旧项目迁移

1. 安装本阶段生成的 NSIS 安装包并启动 FishTongue。
2. 分别新建项目、打开一个 Phase 6 旧项目；确认均能正常进入且原数据存在。
3. 关闭并再次打开旧项目，确认可继续编辑，没有重复迁移或启动错误。

## B. 全局撤销与重做

1. 依次修改一个词条、一个语素、一个语言基本属性和一个历史事件。
2. 在非输入框区域按 `Ctrl+Z`，确认最近一次操作整体撤销；按 `Ctrl+Y`，确认整体恢复。
3. 通过“编辑 → 撤销/重做”重复一次，确认菜单与快捷键一致。
4. 撤销后执行一个新的正式修改，确认旧操作不能再重做。
5. 修改一个词条并关闭项目；重新打开后立即撤销，再重做，确认历史仍在。
6. 选中文本框内容并输入文字，按 `Ctrl+Z`；确认只撤销输入内容，不撤销项目数据。CodeMirror 音变编辑器也重复一次。
7. 撤销某操作后，以另一条写入路径修改同一对象，再尝试重做；确认系统提示冲突且保留后来的修改。
8. 停留在“历史事件”和“阶段管理”等页面，直接撤销或重做当前页面刚完成的操作；确认页面内容立即变化，无需切走再进入。

## C. 原子性抽查

1. 提交一个包含多个候选的造词审核批次，再全局撤销；确认本次生成的词条、词义和关系一起消失。
2. 重做后确认它们一起恢复。
3. 保存或提交过程中强制关闭应用一次，再重新打开项目；确认项目能恢复到操作开始前的完整状态，不出现半条记录。

## D. 历史阶段词典

1. 为语言启用至少两个可见历史阶段，并设置后一个阶段继承前一个阶段。
2. 进入后一个阶段的词典，确认继承词条标有“继承”及来源；编辑该词条并保存。
   同时确认编辑区顶部和底部的保存、删除按钮均可用。
3. 确认当前阶段显示“本阶段”，切回来源阶段后原词条没有被修改。
4. 在当前阶段删除继承词条，确认只产生当前阶段移除覆盖；来源阶段仍保留。
5. 使用撤销/重做恢复和再次删除，确认阶段覆盖随操作正确变化。
6. 创建 `no_data` 无记录阶段，确认词典只读且无法保存词条。

## E. 阶段与返回导航

1. 切换过两个可见阶段，再离开并返回该语言；确认进入最近使用的可见阶段。
2. 检查侧栏、路径栏和选择器，确认看不到“内部默认状态”。
3. 在词典输入筛选条件、选中词条并滚动列表；通过关联词条跳到另一语言，然后点击返回。
4. 确认原语言、原页面、原阶段、筛选条件、选中词条和滚动位置均恢复。
5. 从项目主页、关联词条等外部入口进入一个已有历史阶段的语言；确认读取阶段时显示“正在读取阶段”，随后路径栏显示真实历史阶段，而不是内部默认状态。
6. 新建一门语言并进入概览；确认路径栏立即显示“默认状态”，不应长时间显示“正在读取阶段…”。
7. 若阶段读取确实失败或超过 3 秒，确认路径栏改为“阶段读取失败”，状态栏给出原因，阶段菜单中可以点击“重新读取阶段”；不得永久停留在加载状态。

## 通过标准

- A～E 所有步骤通过；没有数据丢失、半写入或内部默认状态泄漏。
- 若失败，请记录步骤、项目来源版本、操作对象、是否重启及截图。外部人工验收通过前，Phase 7.1 不正式结项。
