# Phase 7.1 风险与处理记录

| 风险 | 影响 | 已采取措施 | 当前状态 |
| --- | --- | --- | --- |
| 多表写入只撤回一部分 | 项目数据不一致 | 一个用户操作记录为一个变化集，并在同一 SQLite 事务中回放 | 已自动测试 |
| 撤销覆盖之后的人工修改 | 用户数据丢失 | 回放前逐行比对期望状态；不一致时报冲突且不写入 | 已自动测试 |
| 写入中断留下半条历史 | 下次打开状态不确定 | 先写 `pending` 快照；失败主动恢复，崩溃后打开项目自动恢复 | 已通过人工验收 |
| 历史无限增长 | 项目膨胀 | 每个项目只保留最近 100 个已完成操作；新操作清空重做分支 | 已实现 |
| 大型项目快照耗时或超过限制 | 保存变慢 | 完成后仅保存实际变化；开始快照设 64 MiB 安全上限 | 残余风险，后续可改为增量捕获 |
| 文本输入时误撤销项目 | 丢失非预期数据 | input、textarea、select、可编辑元素和 CodeMirror 优先使用本地撤销 | 已通过人工验收 |
| 历史阶段编辑污染来源阶段 | 历史数据被改写 | 通过 `StageStateResolver` 读取完整状态，只写当前阶段 `replace/remove` 覆盖 | 已通过人工验收 |
| `no_data` 阶段被写入词典 | 伪造无记录数据 | 阶段词典编辑器禁用保存，Service 继续执行正式校验 | 已通过人工验收 |
| 内部默认状态暴露 | 用户误把内部锚点当历史阶段 | 主导航、路径栏和阶段选择只使用可见的非内部阶段 | 已通过人工验收 |
| 阶段读取异常导致路径栏永久加载 | 用户无法确认当前阶段或继续切换 | 新语言即时采用已知默认状态；查询失败或 3 秒超时后结束加载并允许重试 | 已通过人工复验 |
| 返回后上下文丢失 | 用户重复定位 | 路由历史记录页面、语言、阶段、词条、筛选和滚动位置 | 已通过人工验收 |
