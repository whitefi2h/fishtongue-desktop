# Phase 1.5 页面与功能状态清单

| 区域 | 页面或能力 | 状态 | 是否写入项目 |
| --- | --- | --- | --- |
| 窗口 | 自定义标题栏、窗口控制 | Live | 否 |
| 窗口 | 自定义菜单、导航、状态栏 | Live | 否 |
| 项目 | 新建、打开/导入、保存、另存为、恢复 | Live（复用 Phase 1） | 是 |
| 项目 | 欢迎页、最近项目、失效提示、创建向导 | Prototype + Live 入口 | 仅真实项目命令 |
| 项目 | 主页、语言列表、谱系、事件、设置 | Prototype | 否 |
| 语言 | 概览、属性、阶段、方言 | Prototype | 否 |
| 语言 | 语音学、形态学、三栏词典、书写系统 | Prototype | 否 |
| 演化 | 方案、规则编辑、预览、冲突处理 | Prototype | 否 |
| 接触 | 借词、仿译、结构影响提案 | Prototype | 否 |
| 翻译 | 辅助翻译与缺词审核流程 | Prototype | 否 |
| AI | 上下文范围、引用范围、提案卡片 | Prototype | 否 |
| 工具 | 安全脚本工作台、差异预览 | Prototype | 否 |
| 全局 | 搜索、命令入口、模态框、双主题 | Prototype | 否 |
| 全局 | 中英文界面框架与页面结构 | Prototype | 否 |
| 后续 | 地图、自动历史重构、全局撤销 | Planned | 否 |
| 后续 | 高级不安全脚本、原创文字绘制 | Planned | 否 |

`Live` 只表示界面能够调用已经通过 Phase 1 验收的真实能力，不表示后续语言学模块已经实现。`Prototype` 永远不应产生“保存成功”“规则已运行”或“AI 已生成”等虚假结果。
