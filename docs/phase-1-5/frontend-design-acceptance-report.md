# Phase 1.5 前端视觉阶段验收报告

## 结论

`frontend-design` 阶段的桌面框架、关键页面和功能入口已经落地，可以进入人工视觉验收。旧网页式 Phase 1 页面已退出正式入口；项目文件和数据库底层没有删除。

本报告只验收视觉布局和原型边界，不替代下一阶段的 `emil-design-eng` 交互精修与最终 `web-design-guidelines` 审查。

## 已完成

- 自定义 36px 标题栏、28px 菜单栏、40px 上下文工具栏和 24px 状态栏。
- Tauri 系统标题栏与 Rust 原生菜单已移除。
- 窗口控制经过 Port/Adapter 隔离，React UI 不直接导入 Tauri。
- 项目级、语言级和全局辅助页面均有可达的高保真界面。
- 原型、真实能力和后续功能使用明确状态区分。
- 浅色、深色和中英文结构入口已建立。
- 旧米色、Georgia、大卡片式页面不再进入正式构建。
- 设计令牌升级至 1.1.0，仅增加窗口框架尺寸令牌。

## 人工验收建议

1. 在 Windows 安装版中确认窗口可拖动、双击标题栏可最大化/还原。
2. 检查最小化、最大化和关闭按钮；关闭按钮悬停应显示危险色。
3. 依次打开项目、语言、阶段、方言、词典、演化和开发者工具页面。
4. 确认每个原型页都有“设计预览，不会写入项目”提示。
5. 分别检查浅色/深色、中英文入口及 `1280 × 800`、`1440 × 900`。
6. 确认 AI、演化和脚本页面没有伪造运行结果。

## 未完成与风险

- 菜单焦点移动与返回、模态框焦点陷阱、动效节奏和微交互已由 `emil-design-eng` 完成首轮精修。
- 最终无障碍与 Web Interface Guidelines 验收尚未开始。
- 中英文使用同一页面注册表，当前重点是结构一致；逐句英文文案仍需在最终验收前校订。
- Release 程序已完成启动烟雾测试并成功出现无边框窗口；窗口拖动已改用 Tauri 官方运行环境识别与窗口 API，并已通过真实 Windows 人工复核。

## 人工审查补充

2026-07-25 的人工审查基本通过，并提出浅色表格、窗口拖动和小窗口折叠导航三个问题。三项均已完成代码修复：

- 浅色表格使用语义设计令牌明确设置单元格背景、文字和分隔线，不再受旧全局隔行色覆盖。
- 标题栏空白区域与标题文字统一命中拖动区域；桌面 Adapter 改用 Tauri 官方环境判断和 `startDragging`。
- 折叠导航固定为 48px 图标轨道，隐藏滚动条视觉噪声并保留清晰的展开按钮。
