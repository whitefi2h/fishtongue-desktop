# Phase 4 Windows 人工验收指南

## 准备

- 使用干净 Windows 电脑和 Phase 4 安装包。
- 准备自行申请的 OpenAI、Gemini、DeepSeek 测试 Key；真实请求可能产生少量费用。
- 准备一个 Phase 3 `.fishtongue` 项目。

## 核心步骤

1. 打开 Phase 3 项目，确认正常迁移并可保存、关闭和重新打开。
2. 不配置 AI，回归词典、语素、造词、演化和屈折。
3. 在“工具 → AI 与模型设置”分别添加三家官方服务。
4. 确认填写过的 Key 不会再次显示，只显示“已安全保存”。
5. 勾选联网说明，读取模型列表并执行连接测试。
6. 打开 AI 侧栏，分别测试页面、语言和项目范围。
7. 检查回答下方的实际引用，启动请求后测试“停止”。
8. 让 AI 生成词条、语素、造词配置、演化和屈折提案。
9. 拒绝一个提案，确认项目数据不变；保存一个提案，确认重新打开后存在。
10. 修改目标后尝试应用旧提案，确认系统提示提案过期且不覆盖。
11. 添加一个本机 OpenAI 兼容地址，确认 HTTP 只允许回环地址。
12. 断网后确认全部非 AI 功能正常。
13. 把项目复制到另一台电脑，确认对话存在但必须重新设置 Key。
14. 删除 Provider，确认对应 Windows 凭据一同删除。
15. 卸载、重装并再次打开项目。

## 通过标准

- 项目、日志和设置文件中找不到 Key。
- AI 不能未经确认修改正式数据。
- 取消、断网、认证失败和限流均不损坏项目。
- 关闭应用后无额外进程残留。
