# Phase 4 风险表

| 风险 | 控制措施 | 状态 |
| --- | --- | --- |
| API Key 泄露到项目或日志 | Windows 凭据管理器；数据库无秘密字段；静态与安装包扫描 | 已实施，待外部复核 |
| 项目文本进行提示注入 | 上下文标记为不可信数据；工具白名单；AI 无直接写权限 | 已实施 |
| AI 覆盖用户刚修改的数据 | 保存前重算规范快照哈希；不一致即标记过期 | 已实施 |
| Provider 地址窃取凭据 | 官方地址固定；自定义远程地址强制 HTTPS；同源重定向 | 已实施 |
| 回答、提案或审计只写入一部分 | SQLite 命令触发器原子写入 | 已实施 |
| AI 故障影响本地项目 | Provider 与正式数据服务隔离；失败不执行提案 | 已实施 |
| 模型接口变化 | 独立 Provider Adapter；模型 ID 可手工输入 | 待人工验收 |
| Windows 凭据兼容问题 | 使用原生 Credential Manager；干净 Windows 实机验证 | 待人工验收 |
