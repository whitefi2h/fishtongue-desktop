## 本轮修复

### 历史阶段与方言

- 阶段与阶段上下文继续使用单个原子事务保存，避免只保存一半数据。
- 每次打开项目数据库前由 Rust 显式执行全部待处理迁移；Schema v10 修复既有 v9 项目可能漏迁移的问题。
- 保存后立即刷新阶段列表、上一个时间阶段和数据基础选项，不再要求手动刷新页面。
- 未保存草稿期间禁用重复“新建”，防止误触清空正在填写的内容。
- “无记录”阶段不能再被选为数据基础，也不能携带继承数据。
- 阶段与方言采用紧凑主从布局，移除大面积灰色空表格。

### 语言谱系、历史事件与词源

- 语言谱系已推倒重做为只读 SVG 树画布：支持滚轮缩放、`Ctrl + 左键`拖动、适合窗口、语言节点阶段展开和多根语言。
- 继承是默认主图层；接触与方言可独立叠加，并使用不同线型区分。
- 关系创建、查看和删除移至“语言 → 基本属性 → 语言关系”，谱系页不再混入编辑表单。
- 历史事件改为时间线与编辑器组合，参与语言可以明确选择。
- Schema v11 为词源关系增加可选历史事件关联，删除事件时安全解除关联；Schema v12 持久化完整语言基本属性。
- 词源录入先选择来源语言，再通过可见检索结果选择该语言的词条；不再使用混合所有语言的巨大原生下拉框。
- 词源和历史事件列表改为紧凑、可读的关系列表，并加入二次删除确认。

### 演化审核与目标阶段

- 演化审核增加全选、选中计数、批量接受和批量拒绝。
- 接受并提交的结果会刷新目标阶段数据；切换到目标历史阶段的词典后可立即查看解析后的词条。
- 历史阶段词典以只读方式展示完整解析状态，避免编辑时覆盖来源阶段。
- 修复 CodeMirror 初始化竞态：编辑器不再先以空内容启动并覆盖刚加载的 Lexurgy 规则。

### 桌面界面与操作安全

- 搜索、筛选和新建只在确有对应功能的页面显示，不再机械复制到每个页面。
- 页面切换后主工作区回到顶部，避免保留上一页滚动位置。
- Phase 5 表格、列表、空状态和表单统一使用既定设计令牌，补齐浅色与深色模式。
- 所有 Phase 5 删除操作采用应用内二次确认，不使用浏览器原生弹窗。
