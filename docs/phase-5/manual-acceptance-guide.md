# Phase 5 Windows 人工验收指南

使用一台无 Java、Node.js、Docker 的干净 Windows x64 电脑。

1. 安装 FishTongue，打开一个 Phase 4 项目。
2. 检查旧词典、语素、造词配置、演化、屈折和 AI 会话。
3. 打开阶段管理；没有可见阶段时确认语言仍可正常工作。
4. 新建历史阶段，分别填写时间父级和数据基础。
5. 新建无记录阶段，确认只能填写背景和关系。
6. 新建轻量方言，确认显示“继承 + 差异”。
7. 在语言谱系建立多个根、继承关系和接触关系。
8. 尝试建立循环关系，确认应用拒绝且现有关系不变。
9. 创建历史事件并关联参与语言。
10. 创建继承、借词和同源词源关系。
11. 运行正向演化审核并确认来源阶段不变。
12. 关闭应用再打开项目，复核全部数据。
13. 另存为后分别修改两个项目，确认互不影响。
14. 退出应用，确认没有 Java/Lexurgy 残留进程。
15. 断网重启、卸载重装并再次打开原项目。

发现任一数据丢失、来源覆盖、循环谱系或无法关闭应用，均视为验收不通过。
