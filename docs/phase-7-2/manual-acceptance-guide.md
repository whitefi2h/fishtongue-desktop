# Phase 7.2 Windows 人工验收指南

> 前提：先运行 `npm run verify:phase7-2` 并保存完整日志。本指南必须在 Windows 安装包中执行，不能用开发浏览器代替。

## A. 核心演化工作流

1. 打开一个由旧版本创建、已保存演化规则的项目，确认它出现为“默认演化方案”，规则和测试词完整。
2. 新建两个方案；分别复制、重命名、归档、恢复；建立版本后关闭并重新打开项目。
3. 连续编辑同一方案并等待多次自动保存。全局撤销应一次恢复本段编辑；保存失败时编辑器内容仍保留并可重试。
4. 在 IPA 模式选择正常 IPA、缺少 IPA、临时 IPA 三类词。运行确认框中的数量必须正确；缺少 IPA 的词不得使用显示词形代替。
5. 运行包含变化、无变化、同音、同形、新音位和非法 IPA 的规则；逐词查看中间阶段和逐规则追踪。
6. 从成功运行建立两个独立提交草稿。确认目标拼写默认待确认；测试批量保留来源拼写和批量跳过。
7. 分别提交到新历史阶段、已有阶段、已有轻量方言和新后代语言。每次确认来源词典不变。
8. 对四种提交分别执行全局撤销和重做；确认没有半成品，图中的提交标记同步移除和恢复。
9. 在运行后修改来源词条或音系，再尝试提交；修改目标词典或阶段后再尝试提交。两者都必须阻断旧状态。
10. 测试“按原输入复现”和“按当前内容重跑”。更换不可用的引擎版本记录时，界面必须明确说明不能完全复现。

## B. 后代语言完整性

1. 来源状态准备未选择词、缺少 IPA 词、被跳过词、多义词和带语素连接的词。
2. 创建后代语言后确认：参与词使用确认结果；其余词原样继承；Sense、语素及连接完整；存在主要遗传关系和继承出处。
3. 撤销后确认新语言、阶段、词典、语素、关系和出处全部移除；重做后编号和内容与原提交一致。

## C. 演化图与可用性

1. 展开语言节点，确认内部默认状态不显示；阶段、方言、后代语言位于正确关系中。
2. 区分主要遗传、接触/方言图层和演化提交标记。年代为空或自由文本时不得伪造比例位置。
3. 用键盘聚焦语言节点、阶段和演化标记；从标记打开准确的方案、运行和提交。
4. 在浅色、深色、1360×860 和 1280×800 下完成主要流程；检查原生下拉、禁用态、焦点和错误信息。
5. 用 5,000 词项目筛选、选择、滚动和取消运行；界面不能整体横向滚动或长时间失去响应。
6. 断开网络并停用 AI，重复方案、运行和提交主流程。

## D. 本轮修正复测

1. 已有可见历史阶段时进入演化页，来源阶段不得显示或自动选中内部 `Default state`。
2. 收起“方案与历史”侧栏，确认主编辑区变宽；再次展开后，方案、版本、运行、提交和检查信息仍完整。
3. 用“借词”来源筛选确认真实借词可以单独筛出；“全选”和“反选”只作用于当前筛选结果。
4. 在没有配置正式音位表时运行 IPA 演化，只显示一次“已跳过音位检查”的整体提示，不得逐词误报字母、重音符号和音节分隔点。
5. 配置正式音位表后重跑，确认真正未登记的音位仍能被识别。
6. 新建提交草稿后确认“正式提交”暂不可用；完成拼写决定并点击“重新检查”后，按钮应明确显示检查进度。
7. 没有同音冲突时不得显示同音确认框；检测到同音时，显示标准尺寸的“允许该词与其他词同音”复选框。
8. IPA 中的重音符号和音节分隔点不得成为阻断问题；真正无法识别的 IPA 字符仍须阻断。
9. 目标音位表缺少演化结果中的音时，检查结果应列出不重复的新增音。点击“配置 N 个新增音”，逐项选择“独立音位”或“音位变体”；变体必须选择所属音位，分布/条件应按实际 Lexurgy 规则自动预填且允许修改。点击“保存配置并重新检查”后应立即显示进度和新检查结果，不再需要额外点击一次“重新检查”。
10. 分别把新增音保存为独立音位和音位变体并正式提交。打开目标阶段/语言的音系页面，确认符号、角色、所属音位及分布条件正确；全局撤销后这些音系差异与词典变更同时消失，重做后同时恢复。
11. 修改已检查的草稿后，“正式提交”应重新禁用，直到再次检查；正式提交期间应显示“正在提交…”，窗口保持可操作。
12. 依次打开版本、运行和提交记录，每次点击左栏当前方案都应立即返回同一方案的“演化方案草稿”；当前高亮必须与主工作区一致。
13. 准备一个没有正式词典词条、但方案中有测试词的阶段。点击“试跑测试词”应显示逐词临时结果；试跑前后版本、运行和提交数量均不增加，也不能从该结果进入正式提交。
14. 打开任一运行记录并逐行切换结果。运行摘要必须始终从主工作区顶部开始，不得出现会随选中行高度变化的大块空白。
15. 点击“配置 N 个新增音”后必须在当前视野中央打开配置窗口；选择“音位变体”的所属音位后保存，窗口应在保存成功后关闭，且新增音阻断应被移除。字段不完整时窗口保持打开并聚焦第一个错误字段。
16. 方案草稿顶部按钮应显示为“复制”“归档/恢复”“删除”“运行”；“运行”保持在操作组最右侧，不显示“固定输入并运行”等内部实现措辞。
17. 目标类型选择“新的后代语言”并正式提交。提交成功后无需关闭项目或重新进入页面，新语言应立即出现在项目语言列表；进入该语言后应能看到首个可见阶段和继承后的词典。
