# Phase 7.2 验收报告

> 当前结论：**尚未结项**。

## 已实现的开发内容

- Schema v17 与旧演化方案迁移。
- 多方案、不可变版本、确定性输入快照、运行与逐词追踪。
- IPA 默认输入、临时 IPA、拼写确认和提交冲突检查。
- 新阶段、已有阶段、轻量方言和新后代语言的统一事务提交入口。
- 项目级撤销/重做覆盖 7.2 数据；连续方案保存具备合并键。
- 统一工作台与基于正式阶段、关系和提交记录推导的演化图。
- 修复演化工作台阶段选择、可收起侧栏、借词来源筛选和空音位表误报。
- 修复提交草稿未保存屏幕修改、IPA 韵律符号误报、并发检查卡顿和同音确认控件歧义；阻断问题现在在主工作区分组显示。
- 统一方案、版本、运行和提交之间的返回行为：方案行始终返回可编辑草稿，并增加不读取词典、不产生历史记录的测试词临时试跑。
- 新增音改为结构化音系配置：可选独立音位或音位变体，分布/条件从 Lexurgy 规则与逐词结果预填；确认后自动重新检查，并在正式提交时与目标阶段/语言数据原子写入。
- 修复运行记录受旧全局 `main { margin: auto }` 影响而垂直漂移的问题；结果区现在固定从主工作区顶部开始。
- 新增音配置改为当前视野内的模态配置窗口，并修复“所属音位”选择被旧状态覆盖、导致音位变体无法保存的缺陷；方案操作按钮同步精简为“复制 / 归档 / 删除 / 运行”。
- 修复“提交为新的后代语言”后项目语言清单仍使用旧缓存的问题；提交应用服务现在会在原子写入完成后重新读取语言清单，新语言会立即进入项目导航。
- 修复项目主页、语言列表和语言概览始终显示 0 或占位词条数的问题；统计现在读取真实语言词典，历史阶段读取解析后的有效词典。
- 提交检查改为一次批量 IPA 分析，避免逐词重复启动 Analysis Sidecar；检查期间持续显示进度。已提交和已撤销记录改为明确的只读状态，不再提示可以重复提交。
- 演化工作台按可用宽度自动收起方案与历史侧栏，主工作区列宽允许安全收缩；桌面窗口在收到关闭请求时提前清理 Lexurgy 与 Analysis Sidecar，并在销毁事件再次兜底。
